
# E-Commerce and Digital Banking Platform

A Django REST Framework based project that combines
E-Commerce functionality with a simulated Digital Banking system.

## Technologies Used
- Python 3.10
- Django 5.2
- Django REST Framework
- SQLite
- JWT Authentication
- Postman
- Git and GitHub

## Current Modules
- Custom User Model
- Customer Registration API
- JWT Login and Token Refresh
- Protected Profile API
- Role-Based Access Control (RBAC)
